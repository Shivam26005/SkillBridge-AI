
# SkillBridge AI v4 - SIH Judge Demo Flow

## 1. Start
Open the landing/dashboard and explain:
"SkillBridge AI connects students, academia and industry through a closed-loop skill intelligence system."

## 2. Student journey

demo@student.com / demo

## 6. Signature feature for judges

### Career Gap Simulator
For a target role, calculate:

Readiness = weighted current skill coverage / weighted required skill coverage × 100

Then show:
- Current readiness
- Missing skills
- Weak skills
- Priority learning roadmap
- Recommended opportunity

This creates the closed loop:

Assessment
→ Skill Profile
→ Skill Gap
→ Learning Roadmap
→ Verification
→ Internship/Job
→ Mentor Feedback
→ Portfolio
→ Placement

## 7. 60-second pitch

"SkillBridge AI is an intelligent academia-industry collaboration platform. Students assess and build their skills, receive explainable AI gap analysis and opportunity recommendations, while industries discover candidates based on actual skills. Faculty can run FDP, research and mentorship programs, and institutions get analytics showing placement readiness and industry skill demand. Our core innovation is a closed-loop career engine that converts skill gaps into actionable learning and then connects learners to verified opportunities."
